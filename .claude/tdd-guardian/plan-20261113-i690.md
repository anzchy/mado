### WI-2: Atomic AnnotatedCopyWriter in MadoInfrastructure (receipt I690-WI-2)
- **Description:** `MadoInfrastructure/Annotation/AnnotatedCopyWriter.swift` and `ImageIOWritableTypes.swift`.
  - **Write steps:**
    1. Take a lease.
    2. Encode to a hidden temporary file in the destination folder (`.<name>.mado-tmp-<uuid>`).
    3. `renamex_np(RENAME_EXCL)` into place.
    4. On `EEXIST`, try the next `-n`, up to a bound, then fail with `.nameExhausted`.
  - **Panel path:** when the user confirms replacing another file, `replaceItemAt` from the temporary file.
  - **Before the final move:** re-check the source's identity and that it still exists.
  - **Typed failures:** `permissionDenied`, `diskFull`, `folderMissing`, `sourceMissing`, `sourceIsTarget`, `encodeFailed`, `nameExhausted`, `accessLost`.
  - **Metadata:** none of the source's EXIF, GPS or IPTC is copied, and there is no orientation tag.
- **Acceptance criteria:**
  - [ ] **Success:** the copy decodes to the flattened pixels with the right type. The folder then holds exactly the source plus the copy, and the source is unchanged.
  - [ ] **Late clash:** a file that appears at the planned name before the move gives `-2`. The clashing file is unchanged.
  - [ ] **Failures:** every failure leaves the source unchanged, no temporary file and no target.
  - [ ] **Source as target:** a hard link to the source, or a case variant of its path, fails with `.sourceIsTarget` before any byte is written.
  - [ ] **Lease:** the write happens only while a lease is held. If the lease cannot be acquired, the writer fails with `.accessLost`. Every lease is released.
- **Required tests** (MadoInfrastructureTests, real temporary folders):
  - writes a decodable copy;
  - retries on a late clash;
  - name exhausted;
  - permission denied (`chmod 0555`);
  - folder gone;
  - hard link and case variant;
  - encode failure;
  - a failure-at-any-step law that injects a failure at each step boundary;
  - errno mapping;
  - writes only inside a lease;
  - panel replace is atomic;
  - source missing.

### WI-4: Annotate Mode state, key routing and save wiring (receipt I690-WI-4)
- **Description:**
  - **Model, in MadoApplication:**
    - `Annotation/AnnotateMode.swift`: the document, the source, and a pending `AnnotateUnsavedPrompt(reason: .escape | .closeWindow | .quitApp | .changeImage)` with `resolve(.save | .discard | .cancel)`.

    - `CommandID` is not extended.
  - **Native wiring:** `CanvasWindowController` handles entry and exit, key routing, `windowShouldClose`, image-change requests, the ⌘S save task (re-planning to the panel on `.permissionDenied`), and the `undo:`, `redo:` and `copy:` actions. The `CommandMenu` gets Annotate ⌘E and Save Annotated Copy ⌘S. The prompt is a temporary `NSAlert`; its visual form is deferred.
- **Acceptance criteria:**
  - [ ] **Entering:** ⌘E works only while viewing a shown image. It is disabled in the Grid, empty, reading, Lost Access and read-failed states, and while typing. Pressing it again while active does nothing.
  - [ ] **Browsing off:** while active, browsing commands are disabled in the Session and in the menu, and ←/→ change nothing. Zoom and fit stay enabled.
  - [ ] **Esc:**
    - with no unsaved marks, it exits;
    - with unsaved marks, it asks;
    - Cancel keeps everything;
    - Discard exits;
    - Save exits only after the write succeeds; a cancelled panel or a failed write keeps the marks and the mode.
  - [ ] **Close, quit or image change:** each one asks when marks are unsaved. Cancel aborts it.
  - [ ] **R:** selects the rectangle tool only in Annotate Mode and not while typing. Outside the mode it is not consumed.
  - [ ] **⌘S twice:** writes `-annotated`, then `-annotated-2`. The mode, the original image and the Preview Set stay as they were, and nothing is unsaved afterwards.
  - [ ] **Unwritable folder:** ⌘S opens the prefilled panel. Cancelling the panel keeps the marks.
  - [ ] **Source deleted or folder unreadable:** ⌘S reports the reason and keeps the marks and the mode. The Preview Set does not move on.
  - [ ] **⌘C, ⌘Z, ⇧⌘Z:** ⌘C copies the flattened image without writing a file and without changing the unsaved state. ⌘Z and ⇧⌘Z undo and redo marks.
- **Required tests:**
