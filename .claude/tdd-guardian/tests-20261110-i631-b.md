# #631 Round b test matrix

Plan: `plan-20261110-i631-b.md`. This matrix was audited after implementation had begun; it is not independent pre-implementation evidence. The late adversary found gaps in misleading summaries, same-LCOV parity and per-callback coverage proof; the first two are now in Node tests and the last is a required native report check.

## WI-1 strict denominator and pinned exceptions

| Case | Level and specification | Mock boundary | Refactor resilience |
|---|---|---|---|
| Complementary and overlapping FNDA hits merge once per mapping; DA lines also union | Level 1 output; S5 union/idempotence | None; real parser and files | Internal map structure may change without changing totals |
| New zero-hit FNDA fails with raw denominator increased while FNF/FNH remain 100% | Level 1 output; S3 failure mode | None | Summary parsing may change but strict result stays failing |
| One pinned exception reports raw, exception and eligible totals separately | Level 1 output; S3 exception policy | None | Report implementation may change while categories remain explicit |
| Duplicate, wildcard, unmatched, moved, covered, digest-drifted and toolchain-drifted exceptions fail | Level 1 exit/report; S3 failure modes and S5 transition from uncovered to covered | None | Validation strategy can change; invalid artifacts still fail |
| Missing or malformed evidence, mismatched source inventory and incompatible shard mappings fail | Level 1 exit/report; S3 failure modes | None | Metadata parser may change, rejection remains |

The coverage merge has a union/idempotence law: overlapping hits do not add mapping identities. The exception policy has a state-transition law: an entry becomes invalid when its mapping becomes covered.

The production source change moved the three hover thunk mappings from the brief's original line numbers; the fresh report has no uncovered production function.
