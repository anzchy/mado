**Plan**: `.claude/tdd-guardian/plan-20261101-345-fix1.md`

## Unit: CanvasWindowController.returnToGrid + GridBrowserView reveal

**Law**: After Grid→preview→wrap→Esc, selection is conserved, the latest viewed item becomes Current Item, and reveal moves the restored viewport only enough to contain its tile. If already contained, offset is invariant across the round trip. Cases V/O/U cover this S5 law using actual controller and AppKit geometry.

### Case V: Already-visible wrapped landing conserves saved offset
- **Category**: state
- **Lane**: integration — configured compiled `app-red` lane, real controller and AppKit.
- **Spec level**: S5 — viewport and selection conservation across Grid→preview→wrapped viewing→Grid.
- **Input**: Actual valid PNG folder large enough to scroll; restored viewport in middle of folder. Select IDs 24/25, current 25, origin chosen from tile24.minY minus top inset minus 40.25; require both tiles fully visible and earlier tile measurably below effective viewport top. Space, loop on via installed menu, next wraps to 24, wait for image settle, Esc.
- **Expected output**: Landed ID equals expected earlier selected ID before/after Esc; Grid current matches it; original selected ID set survives; tile remains fully visible; saved contentOffset equals returned contentOffset exactly.
- **Observable side effect**: Real NSScrollView viewport remains at saved offset and real image is decoded.
- **Assertion strategy**: Level 3/4 — require both candidate frames are fully visible and earlier tile is not top-aligned before preview; assert rendered image identity, grid current and exact offset equality after Esc.
- **Mock boundary**: none — real controller, GridBrowserView, NSScrollView, filesystem fixture and ImageIOPipeline; in-memory preference storage is the real repository implementation.
- **Refactor that would break this**: Changing user-observable scroll or return-current behavior; internal method renaming does not.

### Case O: Below-viewport wrapped landing aligns only to bottom edge
- **Category**: boundary
- **Lane**: integration — compiled `app-red` lane.
- **Spec level**: S5 — conservation and minimal displacement across the same round trip with an offscreen destination.
- **Input**: Actual long image folder; select IDs 12/36, current 12; saved viewport origin tile12.minY minus top inset minus 40.25 contains earlier selected current and later selected ID lies below effective viewport bottom. Space, enable loop, previous wraps to 36, wait for image settle, Esc. Assert geometry preconditions before acting.
- **Expected output**: Landed tile fully visible, target.maxY equals effectiveVisible.maxY within geometry tolerance; offset movement equals target.maxY minus oldEffectiveVisible.maxY; horizontal offset unchanged, selected set preserved.
- **Observable side effect**: Real clip origin shifts down by the minimum distance.
- **Assertion strategy**: Level 3/4 — assert offscreen-below precondition, independently compute minimum shift from pre-preview frames/viewport, assert returned offset and tile containment. This rejects .top placement and “never scroll”.
- **Mock boundary**: none — real implementation and temporary PNG fixtures.
- **Refactor that would break this**: Changed observable clipping/reveal behavior, not private structure.

## Unit: GridBrowserView ItemID reveal API

**Law**: Reveal is idempotent once its target is fully visible; unknown identity does not alter state. It preserves selection/current identity. Package cases supplement the required App RED and cover new package executable lines.

### Case G: Valid IDs reveal minimally and repeat without movement
- **Category**: state
- **Lane**: unit — real in-process AppKit view/window, package suite.
- **Spec level**: S5 — reveal then repeated reveal keeps the same origin; selection/current remain unchanged.
- **Input**: Real grid fixture with 120 IDs and nonzero content insets; reset to a saved middle viewport for every valid ID, covering visible/above/below partitions from actual geometry; invoke public ItemID reveal, then repeat. Use a parameterized bounded identity domain, without claiming randomized generation.
- **Expected output**: Visible target preserves offset; above target aligns minY with effective viewport minY; below target aligns maxY with effective viewport maxY. Repeating each reveal leaves resulting offset unchanged.
- **Observable side effect**: Clip origin and tile containment.
- **Assertion strategy**: Level 3/4 — geometry and state comparisons; assertions do not inspect call counts/private method names.
- **Mock boundary**: none — real GridBrowserView/NSScrollView and FolderSnapshot entries.
- **Refactor that would break this**: An observable reveal law change.

### Case M: Unknown ItemID is a no-op
- **Category**: guard
- **Lane**: unit — package suite.
- **Spec level**: S2 — identity lookup's absent partition.
- **Input**: ItemID absent from populated grid; save contentOffset/selection/current first.
- **Expected output**: All saved state unchanged, no crash.
- **Observable side effect**: none.
- **Assertion strategy**: Level 4 — compare saved state and offset.
- **Mock boundary**: none — real grid.
- **Refactor that would break this**: Changing unknown-ID contract only.
