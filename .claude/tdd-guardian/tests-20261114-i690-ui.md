# Test Matrix — #690 P7-11 Annotate Mode, visual WIs (WI-5 package, WI-6 App)

Plan: `plan-20261114-i690-ui.md`. Binding rows: `~/.picsee/herdr/opus-imple-2/i690-ui-addendum.md` B1–B11. Oracle: `design/prototypes/picsee-browser/states/annotate.html` CSS (lines 69–113, 133–175).

**Conventions.** Every package test is `@Test(.timeLimit(.minutes(2))) @MainActor`; every AppTests case is `.timeLimit(.minutes(3))` inside `Issue690AnnotateModeTests` (serialized). All frames are top-left (flipped) coordinates in the 1280×800 container or window content view, unless noted. "±1" is the addendum's native-metric tolerance and appears only where text metrics decide the value. "bitmap" means the `canvasBitmap` pattern (`cacheDisplay` into a 1× rep). "image" is a synthetic `DecodedImage` with `sourcePixelSize` 1600×2400, built as in `CanvasViewTests.canvasImage`.

**Lanes.**
- `unit` = `swift test` (MadoCore, MadoApplication, MadoMacUI on real in-process AppKit views), receipt I690-WI-5 `swift-red`.
- `integration` = AppTests: real `CanvasWindowController`, `FileAccess`, ImageIO and the filesystem, window 1280×800 ordered out, receipt I690-WI-6 `app-red`.
- node tests = `node --test scripts/design/shortcut-model.test.mjs`.

**Mock boundary.** None, except:
- (a) `revealInFinder`, which stands in for `NSWorkspace.activateFileViewerSelecting`, a Finder IPC boundary. The real path is the device smoke (plan "Still open"); there is no hosted integration case, and that is recorded under Deferred.
- (b) The existing `Issue690FakeUI` stays in the older tests. The new B9/B10 cases use the **default** in-window UI, so the real sheet and confirmation are exercised.

View callbacks (`onTool`, `onDragMark`, …) are the views' public output and are not mocks. WI-6 cases bind them to the real session.

**Property tooling.** SwiftCheck is not a dependency. S4/S5 cases use the repo's seeded `AnnotationRandom` loops (pattern: `annotateKeyPolicyNeverConsumesOutsideMode`, 300–500 seeds, seed printed in the message). This is a generated domain without shrinking, and is stated as such.
