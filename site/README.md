# Mado help site

Static pages published to GitHub Pages (https://anzchy.github.io/mado/). Source of truth for the long how-to and privacy text that Settings links to with 「了解更多 ↗」 (Settings keeps one short line per row).

- Only this folder is published (workflow `.github/workflows/pages.yml`); nothing under `docs/` is.
- Pages are marked `noindex` and "draft" until each step and link has been checked against the real service page.
- Plain HTML, no scripts, no remote fonts or images.
- Chinese only for now; an English set is a follow-up.
