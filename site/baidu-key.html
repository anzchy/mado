获取百度 OCR 访问密钥

使用百度云识别文字时需要访问密钥。没有访问密钥时，「识别文字」会使用本机识别并标明。

使用百度文字识别需要一个完成实名认证的百度账号；百度文档列出的证件只有中国大陆证件。百度会把上传的图片保存多久、在中国大陆以外能否使用，目前都未经确认。
  1. 在百度智能云控制台为你的应用开通「通用文字识别」。
  2. 取得应用的 API Key 和 Secret Key。
  3. 回到 Mado：设置 › 截图 › 文字识别，在「访问密钥」中填写两项，然后点「保存到钥匙串」。

上传适用百度服务条款。

Baidu OCR access keys (English)

Baidu text recognition needs access keys. Without them, Recognise Text uses on-device recognition and says so.

Baidu text recognition requires a Baidu account with real-name verification; its documentation lists only mainland Chinese ID documents. How long Baidu keeps images and whether its service works outside mainland China are unconfirmed.
  1. Enable "General Text Recognition" for your app in the Baidu AI Cloud console.
  2. Get the app's API Key and Secret Key.
  3. Back in Mado: Settings › Screenshots › Text Recognition, enter both under Access Keys, then click Save to Keychain. Keys are kept in the macOS Keychain.

Uploads are subject to the Baidu Terms of Service.
