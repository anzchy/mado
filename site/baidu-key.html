获取百度 OCR 密钥

只有你想用百度云识别文字时才需要。不用也可以：识别文字默认使用本机。

使用百度文字识别需要一个完成实名认证的百度账号；百度文档列出的证件只有中国大陆证件。百度会把上传的图片保存多久、在中国大陆以外能否使用，目前都未经确认。
  1. 登录百度智能云，开通“通用文字识别”（general_basic）。
  2. 创建应用，得到 API Key 和 Secret Key。
  3. 回到 Mado：设置 › 截图 › 文字识别，分别粘贴并点“保存到钥匙串”。

具体页面名称发布前需要对照百度控制台核对。
